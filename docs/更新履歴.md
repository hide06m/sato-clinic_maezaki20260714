## 2026-07-24

### 多言語対応（Language切替への対応漏れ修正）

- `medical.html`：導入文と7項目の診療内容カードを5言語（日本語・英語・繁體字・簡体字・韓国語）に対応
- `about.html`：Language切替時に発生していたレイアウト崩れを修正
  - 「医院の理念・方針」の花びら状レイアウトで、英語など文章が長くなる言語で項目同士が重なる不具合
  - カード見出し（診療方針／地域に根ざした医療 等）が2行に折り返す言語で本文と重なる不具合
  - 見出し画像（`about_en.png`ほか）が正方形キャンバスで書き出されており、日本語版より大幅に縦長になっていた画像を、日本語版と同じ比率にトリミング（`medical_ko.png`も同様の不具合を修正）
  - スタッフ紹介モーダルの「専門分野」「コメント」欄が日本語のまま切り替わらなかった不具合
- `faq.html`：Q&A本文（質問11件・回答11件、JS非対応時の一覧を含む）を多言語対応
- `contact.html`：フォームのバリデーションメッセージ・完了メッセージ・氏名の入力例・お問い合わせ種別（プルダウン選択肢／切替ボタンのラベル）を多言語対応

### バグ修正

- モバイル版：スクロール後にハンバーガーメニューを開くとヘッダーが画面から消える不具合を修正
  - 原因：メニュー開閉時に `body` へ `overflow: hidden` を付与しており、`position: sticky` のヘッダーの基準がビューポートから `body` にずれていた
  - 対応：`overflow: hidden` の付与先を `body` から `html` に変更

### コミットメッセージ案

- `多言語対応の漏れ修正とモバイルメニューの不具合修正`

### admin.html の改修

- CMS管理画面モックをフロントサイト全体の実データに合わせて拡充
  - 公開サイトへ戻る導線を追加（従来は戻る手段がなかった）
  - ダッシュボードに件数タイル（お知らせ・診療内容・スタッフ・FAQ・公開ページ・対応言語）を追加
  - お知らせ管理の一覧が3件のみだったのを実際の5件（公開日付き）に修正
  - 診療内容管理・スタッフ管理・よくあるご質問管理・多言語管理のセクションを新設
  - 固定ページ管理を、曖昧な説明文から実際の公開全8ページへのリンク一覧に変更

### GitHub Pages公開前の最終確認（QA）

`docs/掲載原稿.html`・`docs/制作依頼書.html` を基準に、公開対象の全9ページ（`admin.html`除く）を横断的に確認し、以下の不具合を修正:

- フッター・access.html（お問い合わせ欄）・contact.html（ご案内欄）の電話／メールリンクが、言語切替処理で`textContent`を直接上書きしていたため`<a>`タグごと消えて無効なテキストになっていた不具合（初回表示時から全ページで発生）
- access.htmlの導入文が掲載原稿の指定文言と異なる独自の要約文になっていた誤記
- access.htmlの繁體字・簡体字・韓国語の翻訳データが丸ごと欠落しており、選択しても日本語にフォールバックしていた不具合
- news.html／news-detail.htmlの見出し・前後記事ラベル・「最新のお知らせ」等が、翻訳関数の配線漏れ（未定義関数を参照してエラーになっていたため呼び出されていなかった）により一度も多言語化されていなかった不具合
- 全サブページの見出し画像のalt属性が、言語切替後も常に日本語文言へ上書きされ続けていた不具合（アクセシビリティ）

このほかレスポンシブ確認（360〜1440px の7段階）、機能確認（アンカー遷移のヘッダー被り・モーダル・お知らせ前後遷移・路線図拡大・電話メールリンク・文字サイズ切替・画像読み込み）を実施し、問題なしを確認。原稿との文言差分もページ単位で照合済み。詳細な結果と公開可否判定は別途報告のとおり。

### access.html 受付状況ウィジェットの多言語対応

- 「午前／午後受付終了まで」「受付時間外」の見出し・メタ文言は対応済みだったが、時間帯によって表示されるカウントダウン表示（「あと◯時間◯分◯秒」）が言語に関わらず日本語固定だった不具合を修正（index.htmlに設置されている同ウィジェットにも共通で反映）

### first-visit.html の多言語対応

- 「受診の流れ」（4ステップ）・「ご持参いただくもの」・「ご予約について」・「ご来院にあたってのお願い」を5言語に対応
- 見出し画像のalt属性も対応。見出し文言はフッターのサブリンクで既に使われていた翻訳と統一

### admin.htmlへの隠しアクセス方法の拡張

- トップページのFirst ViewカードをすべてFirst View中央の円の中に集めると`desktop-hero-doctor.png`が押下可能になる隠し導線に、パスワード入力ステップを追加（PASS: `admin`）
- 誤ったパスワードの場合はエラーメッセージを表示し、`admin.html`へは遷移しない
